# おさいふ帳

節約と貯金のための家計簿です。`index.html` をブラウザで開けばすぐ使えます（インストール不要）。

## できること
- **使ったお金**を「カード」「現金」「電子マネー」「QR決済」に分けて記録（なにに使ったか・用途・日付）
- **カードの締め日・引き落とし日**を設定すると、いつ・いくら引き落とされるかを表示
- **もらった・入ったお金**を記録（お小遣い・給料・臨時収入など）
- 今月の残り（貯金にまわせる額）と、支払い方法ごとの合計
- **カードの月上限**：8割で「もうすぐ上限」、超えたら「上限オーバー」
- **毎月の貯金目標**と、旅行資金などの**大きな目標**の達成度
- 用途ごとの支出グラフ（カード／現金の内訳つき）と、用途ごとの月予算
- **1日に使える額**：貯金目標とこれからの固定費を残して、月末まで1日いくら使えるか
- **毎月の固定費**：家賃・スマホ代・サブスクなどを登録すると、毎月その日に自動で記録
- **月ごとの比較**：直近6か月の支出グラフと、先月との差（用途ごとにも表示）
- **チャージ**：カードや現金から電子マネー・QR決済へのチャージを、支出と二重に数えずに記録
- 記録のタップで修正・削除、支払い方法ごとの絞り込み
- バックアップの保存・復元（JSON ファイル）

## ホーム画面から起動する
`manifest.webmanifest`・`sw.js`・`icons/` を `index.html` と一緒に https で配信すると、アプリとしてホーム画面に追加でき、オフラインでも開けます。
- iPhone：Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chrome で開く → メニュー → 「ホーム画面に追加」／「アプリをインストール」

## データについて
ファイルを直接開いた場合、記録はそのブラウザ（localStorage）に保存され、外部には送信されません。
claude.ai で公開したページから使う場合は、あなたのアカウントに保存され、本人だけが見られます。
