# かんたん家計簿

節約と貯金のための、ブラウザだけで使える家計簿です。`index.html` をブラウザで開けばすぐ使えます（インストール不要）。

## できること
- 収入・支出をカテゴリ別に記録（日付・金額・メモ）
- 月ごとの収入・支出・残り（貯金にまわせる額）を表示
- カテゴリごとの月予算。8割で黄色、超えたら赤で知らせます
- 貯金目標と達成までの残り額
- バックアップの保存・復元（JSON ファイル）

## データについて
記録はブラウザの localStorage に保存され、外部には送信されません。
ブラウザのデータを消すと記録も消えるので、ときどき「バックアップを保存」してください。
